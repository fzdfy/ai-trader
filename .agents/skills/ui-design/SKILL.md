# UI Design

Read `docs/standards/design.md` and the relevant prototype under `docs/design/prototypes/` before proposing a visual change.

Use the installed `oil-ui` skill to form the visual direction, audit design conflicts, and review real-browser screenshots. Preserve the original prototype and create an exploration copy before editing. Use Preline semantic tokens and the AI Trader workbench composition in the design standard.

Do not copy another product's brand or content. Translate the reference into the project's own hierarchy and vocabulary.

Before completion, inspect desktop and mobile screenshots in light and dark modes and report any visual limitation.
