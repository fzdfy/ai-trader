# 工作台采用无全局顶栏与悬浮助手抽屉

## Status

accepted

## Context

应用级全局顶栏同时承载品牌、页面导航、主题、通知和账户入口，压缩了数据页面的垂直空间，也与左侧业务导航和 AI 助手入口重复。原型稿采用侧栏业务导航、吸顶页面级导航条、主数据区和可展开助手的三区结构。

## Decision

移除应用级全局顶栏，保留 `Apollo Quant / 父页面 / 当前页面`、真实同步状态和站内搜索组成的吸顶页面级导航条，以及页面标题区。子页面使用确定性父级生成可点击面包屑，当前页不可点击，并移除独立返回按钮。品牌、业务导航、数据状态和账户入口进入可收起并持久化的桌面工作台侧栏，展开宽度 238px、收起宽度 68px，并沿用原型的蓝灰渐变和边界色。业务菜单按工作空间、市场情报、量化研究、流程自动化四组展开；同步中心、数据中心和主题设置作为弱化入口放在数据状态和用户卡片之间，以三个 `33×33px` 图标按钮呈现，展开时横排、收起时纵排。工作任务、行情中心和研报洞察使用真实路由展示开发中状态；信号与知识库只从侧栏菜单移除，页面路由与深链接保留。AI 助手由右下角无伪通知点的悬浮按钮打开右侧抽屉，宽屏为主内容让出 392px，窄屏覆盖主内容；抽屉显示真实页面上下文与同步时间，并可进入独立的完整会话页。

## Consequences

数据页面获得更多可用空间，页面级导航条持续提供位置、可点击面包屑、数据状态和站内搜索。代价是宽屏打开助手时主数据区会变窄；移动端一级页面显示菜单，子页面通过父级面包屑返回，完整助手页保留会话历史入口。助手抽屉只展示真实页面名称与同步时间，不向 Agent 注入页面数据上下文。
