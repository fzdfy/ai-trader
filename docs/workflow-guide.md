# 工作流使用说明

## 页面入口

- `/home/workflows`：工作流行式列表，展示触发器、最近运行、启停状态和操作。
- `/home/workflows/new`：创建空草稿后进入画布。
- `/home/workflows/$workflowId`：编辑画布与节点参数。
- `/home/workflows/runs/$runId`：查看版本、触发来源、状态和节点时间线。
- `/home`：今日实际 Workflow Run 摘要。

## 创建与发布

1. 点击“新建工作流”，填写名称和说明。
2. 从左侧拖入一个触发器，再添加股票池、选股、回测、复盘或 AI 因子迭代节点。
3. 灰色端口表示控制流，蓝色细线端口表示标的流。回测节点最多接收一个标的来源。
4. 点击节点打开配置；键盘可用 Tab 聚焦节点，Enter 打开配置，Escape 关闭。
5. 保存草稿不要求图已可发布；发布时系统会检查触发器数量、循环、孤立节点和端口类型。
6. 发布生成不可变版本。修改草稿不会改变已发布版本，需重新发布后自动触发才会使用新图。

## 运行与取消

- 手动运行要求已有发布版本。
- 同一工作流同时最多一个活动运行。冲突触发会写入“已跳过”记录。
- 取消会阻止后续节点；已经发往选股、回测或 AI 的请求可能完成，但结果不会继续传递。
- 节点输出只保存摘要和业务引用；完整选股、回测、复盘和因子结果留在原模块。

## 自动触发

- “交易日定时”使用 `Asia/Shanghai`，非交易日不执行。
- “同步模块完成后”只在指定同步模块成功结束时触发。
- 启用自动触发前必须先发布；停用或归档会移除定时计划。

## 归档

归档会从列表隐藏工作流并停止自动触发，不删除定义和运行历史。运行历史保留 90 天，超过期限由 Workflow Worker 清理。
