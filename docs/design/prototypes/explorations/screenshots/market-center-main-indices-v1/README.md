- `quote/light`、`quote/dark`：七项主要指数行情模式，覆盖成功、加载、空、错误、部分成功、陈旧和桌面 `1440×900` / 移动端 `390×844`。

## 视觉结论

- 上证指数单独全宽展示，并始终标记为“市场基准”。
- 六个风格指数桌面为 `3 × 2`、移动端为 `2 × 3`，顺序和角色标签固定。
- 行情模式逐项显示来源与日期；`930955.CSI` 使用“中证官方 · 收盘”标识。
- 相对大盘模式按百分点超额收益降序展示；有效样本不足时不生成排名。
- 行情和相对大盘共用固定主卡高度：桌面均为 `805px`，移动端均为 `1269px`；相对大盘列表在可用高度内均匀拉伸。
- 独立大类资产轮动位于主要指数区域之后。
