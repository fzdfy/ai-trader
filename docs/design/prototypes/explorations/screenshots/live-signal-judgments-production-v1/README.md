## 原地判断

- 对象总判断位于既有信号面板头部之后。
- 基础信号、K 线形态、高级模型和个股微观结构判断位于对应原层级的内容顶部。
- 总判断中的层级入口可切换到原层；桌面和移动端均保持同一阅读顺序。
- A 股宏观状态由三个核心技术层形成；行业广度、成长/防守继续作为市场背景证据。
- 页面显示 `signal-judgment-1.0.0`，置信度使用“高 / 中 / 低 / 证据不足”文案。
- 个股微观结构只调整置信度，不覆盖三个核心层方向。
