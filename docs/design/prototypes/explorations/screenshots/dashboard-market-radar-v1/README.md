# 每日看板行情雷达视觉证据

## 设计方向

盘前与盘中用户在一个首屏内先确认上证指数、创业板指和伦敦金现货状态，再读可解释的 A 股风险信号，最后进入当前用户的今日 Work Task。视觉沿用暖白画布、蓝灰导航、蓝色主操作、黄色强调和 A 股红涨绿跌。

## 原型

- `../../quant-workbench-dashboard-market-radar-v1.html`

## 证据

- `standard/light/`、`standard/dark/`：桌面 `1440×900` 与移动端 `390×844` 标准首屏。
- `interactions/light/`、`interactions/dark/`：创业板、伦敦金、YTD、键盘焦点和图表悬停读数。
- `interactions/tasks/`：今日任务点击反馈和“全部”进入现有工作任务页。
- `states/light-side/`、`states/dark-side/`：移动端陈旧、证据不足、任务空态和任务错误。
- `states/missing-chart/`：伦敦金单资产缺失时的主图缺失态。
- `states/dark/error-*.png`：深色整体请求错误与重试。

各目录的 `report.json` 保存浏览器检查结果。

## 当前检查

- 标准桌面/移动端浅色与深色：无控制台错误、横向溢出、图片加载失败或文字对比度告警。
- 当前首屏交互：三资产切换、`1D/5D/1M/YTD`、键盘焦点、悬停读数、任务点击和“全部”跳转均通过；跳转后的既有工作任务页不在本次视觉重构范围内。
- 伦敦金隐藏成交量；缺失、陈旧、证据不足、任务空态/错误、加载和整体错误均有独立状态。
- 截图工具仍会报告首屏之外既有看板模块的小字号；该问题继承自基线 `quant-workbench-daily-dashboard-v3.html`，本次未扩大重构范围。
