# 线上最新视觉增量信号矩阵

## 基准来源

以用户提供的线上页面 `https://whtefvmqpezr.shares.zrok.io/home/market` 为唯一视觉基准。通过登录后的真实页面 DOM 保存本地快照，移除了运行脚本、登录会话和账号信息，不保存账号密码。

原始线上页面的直接截图保存在 `source-live/`，用于和增量探索稿对照。

线上页面原有结构完整保留：

- 侧栏、页面级导航和工作台视觉。
- 总览的七项主要指数、行情/相对大盘、成长防守、市场宽度、市场温度和大类资产轮动。
- 板块页的行业/概念切换、排行、热力图、轮动与异动。
- 个股页的搜索、分页、自选和行情列表。
- 快速行情详情的 K 线、均线、MACD、成交量和资金结构。
- 个股分析的价格趋势、研究摘要、情景预测、风险区间、研报、财务和事件。

## 信息层级

- 总览把原“成长 / 防守轮动”和“A 股广度”合并进同一个 A 股宏观状态模块；默认显示综合判断，基础/K线/高级模型在模块内切换。
- 板块列表把技术摘要作为现有排行表的一列，不新增第二张重复列表。
- 板块详情在现有行情、资金、轮动和成分股后用一个技术诊断卡展示完整 32 项。
- 个股列表把技术信号作为现有行情表的一列，不新增重复列表。
- 快速行情详情只显示标签、数据边界和深度分析入口。
- 个股分析把情景预测与风险区间合并，并把技术诊断卡放在价格趋势之后；44 项通过一张卡切换层级。
- 黄金详情用一个技术诊断卡展示完整 32 项，并明确 XAU/USD 的不可用数据。

成长/红利低波不再作为独立展示块重复出现，而是作为 `Risk-On / Risk-Off` 与风格扩散模型的值和证据进入宏观状态模块。

个股分析的价格趋势图不再重复显示一组技术数值；MA/RSI/支撑压力继续通过图表、悬浮读数、技术诊断和风险区间呈现。普通“可用”状态只保留在全局质量条，模块卡只在异常、低置信或缺失时显示状态。

- `market-light/`、`market-dark/`：线上总览。
- `boards-light/`、`boards-dark/`：板块列表。
- `board-detail-light/`、`board-detail-dark/`：板块详情。
- `stocks-light/`、`stocks-dark/`：个股列表。
- `stock-detail-light/`、`stock-detail-dark/`：快速行情详情。
- `analysis-light/`、`analysis-dark/`：个股分析。
- `gold-light/`、`gold-dark/`：黄金详情。
- `signals-*`：新增信号区域截图。
- `states-light/`、`states-dark/`：加载、空、错误、部分成功。
- `interactions-*`：证据展开和键盘焦点。
