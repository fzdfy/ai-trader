# 每日看板设计

## Intent

每日看板用于在开盘前十分钟回答四个问题：数据是否可信、市场是否升温、资金集中在哪些方向、今天有哪些候选标的。工作流和最近复盘继续服务全天跟踪与收盘后复盘。

## Goals

- 所有模块只使用项目现有数据，不生成虚构行情或指标。
- 同时表达当前日期和数据快照日期，避免把旧行情描述成实时数据。
- 首屏先给出市场广度、资金广度、市场温度和候选池，再进入明细。
- 每个模块都能下钻到现有页面，不复制另一套业务流程。

## Non-Goals

- 不新增实时行情源、研报全文或 Agent 数据上下文。
- 不把缺少最新报价的关注列表放进本轮看板。
- 不在本轮修改生产页面；先交付独立设计稿。

## Data Constraints

- 板块、资金流、涨停池和选股池最新完整快照为 2026-08-25。
- 最新资讯截至 2026-08-13，情绪字段尚未标注。
- 最近复盘日期为 2026-11-17，但复盘内容明确提示行情数据存在空档。
- 工作流数据更新到 2026-11-17，其中一条运行记录处于 `pending`。
- 最近同步任务失败，数据健康必须在首屏持续可见。

## Layout

### 1. Daily Brief

页面标题为“每日看板”，显示当前日期、行情快照日期、数据健康状态和“生成每日复盘”主操作。

### 2. Key Metrics

四格指标带：

- 行业广度：445 上涨 / 51 下跌，共 496 个行业。
- 资金广度：271 / 496 个行业主力净流入。
- 涨停温度：65 家涨停，最高 5 板。
- 今日候选：20 只，展示最高评分。

### 3. Market Mainline And Temperature

- 市场主线：行业和概念资金流前五，显示净流入、涨幅和代表个股。
- 市场温度：涨停数、最高连板、封单额和连板梯队。

### 4. Daily Screens And Workflows

- 每日选股：Top 5 标的、评分、来源和进入选股页的入口。
- 今日工作流：运行状态、触发方式、当前步骤和耗时；没有运行时展示空状态。

### 5. Information And Review

- 资讯增量：最新财联社资讯、来源、时间和快照日期。
- 最近复盘：复盘摘要、数据缺口提示和历史复盘入口。

## Visual Direction

- 沿用默认 V2 原型的暖白画布、蓝灰侧栏、白色内容面板、蓝色主操作和黄色状态强调。
- 数据模块使用行式表格、进度条和紧凑列表，不使用同尺寸卡片堆叠。
- 红色表达上涨，绿色表达下跌；数据陈旧和失败状态使用黄色或红色语义。
- 桌面端采用不对称双栏，主要数据和次要上下文并列；移动端收敛为单列。
- 提供浅色与深色主题。

## Interaction And States

- 市场模块统一显示各自快照日期。
- 无数据时保留模块骨架并显示真实空状态，不隐藏整个数据域。
- 模块标题操作链接到现有页面：板块、资金流、选股、工作流、资讯和历史复盘。
- AI 助手仍是唯一悬浮入口。
