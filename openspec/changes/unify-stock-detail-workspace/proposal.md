# Proposal

## Change Metadata

- type: feature
- risk: L1
- baseline: spec
- visual: new-design

## Why

个股快速行情详情和个股分析分别位于 `/home/market/stock/$symbol` 与
`/home/market/analysis/$symbol`。两者都围绕同一个股票对象，共享名称、代码、
行情、技术状态和数据质量，却要求用户再次跳转才能完成深度研究。

本变更将单只股票的两个详情合并为一个渐进式个股工作台：默认快速看盘，用户需要时
在同一页面切换到深度研究。个股搜索首页和多股对比继续独立存在。

## PRD-lite

### 目标用户与场景

- 目标用户：从行情列表、自选股、每日选股或个股搜索进入单只股票的研究用户。
- 默认场景：用户先观察 K 线、资金、预测和关键结论，快速判断是否需要继续研究。
- 深度场景：用户在同一股票上下文内继续查看预测与风险、技术信号、基本面、研报和事件。

### 用户价值

- 同一只股票只保留一个详情入口和一个页面上下文。
- 默认不加载完整研究数据，减少首次打开等待。
- 行情、技术摘要和深度研究共享当前股票、数据日期和返回链路。
- 进入深度研究后不需要重新选择标的或重新建立上下文。

### 成功指标

- 从行情列表或搜索结果进入股票后，不再需要跨路由才能查看深度研究。
- 默认视角只发起轻量行情、K 线、资金和摘要所需的请求。
- 深度研究首次加载失败不影响已显示的行情与 K 线。
- 浏览器前进、后退和刷新能够恢复当前股票与 `quick | research` 模式。
- 桌面和移动端都只保留一个股票身份头和不重复的返回路径。

### 非目标

- 不合并个股搜索首页 `/home/market/analysis`。
- 不合并多股对比 `/home/market/analysis/compare`。
- 不改变行情、预测、风险、技术信号、财务和研报的计算口径。
- 不把所有深度模块一次性加载到默认快速视角。
- 不改变现有个股分析聚合 API 的响应和预测计算；为快速 K 线新增一个只读预测端点，
  只提取既有的 5/20/60 日结果。

## What Changes

- 将 `/home/market/stock/$symbol` 定义为单只股票的唯一规范详情路由。
- 页面增加 `mode=quick | research`，缺省为 `quick`。
- `quick` 展示现有快速行情详情内容：股票身份、报价、K 线、资金、关键信号和简要结论。
- 未来一周预测直接并入 K 线数据画布，只展示一条 P50 中位路径；概率区间用于表达
  不确定性，不绘制多条情景路径。
- 每张技术信号矩阵卡可点击，在右侧抽屉展示该矩阵的全部信号、状态、读数和数据边界；
  卡内固定展示目录前 3 项作为预览，不表示实时重要性排序；移动端抽屉占满可用宽度，
  关闭后焦点回到触发矩阵；抽屉内每一条信号可原地展开证据、数据边界、版本时间、
  规则参数和确认/失效条件。
- `research` 复用现有个股分析内容，在共享股票头下展开预测与风险、技术信号、财务、研报和事件。
- 深度研究区域按需加载；默认 `quick` 不请求完整 `stock-analysis` 聚合数据。
- 点击“深度研究”只更新同页模式，不再导航到另一路由。
- 原 `/home/market/analysis/$symbol` 作为兼容入口，重定向到统一路由的 `mode=research`。
- 原个股分析搜索首页保留，搜索结果进入统一路由的 `mode=research`。
- `/home/market/analysis/compare` 保持独立页面，不重定向。
- 页面切换模式时保留同一股票、K 线周期、来源列表和返回上下文。

## Capabilities

### New Capabilities

- `stock-workspace`: 单只股票详情页的统一身份头、快速/深度模式和渐进式加载行为。

### Modified Capabilities

- `market-center`: 个股列表和行情详情进入统一股票工作台，不再要求跨页进入深度研究。
- `stock-analysis-workbench`: 单股分析作为统一工作台的深度模式打开，旧深链保持兼容。

## Acceptance Criteria

- **AC-1**：单只股票详情的规范 URL SHALL 为 `/home/market/stock/$symbol`。
- **AC-2**：统一页面 SHALL 支持 `mode=quick | research`；无参数时默认 `quick`。
- **AC-3**：`quick` 模式 SHALL 保留现有行情、K 线、资金和关键信号能力，不要求用户先加载深度研究。
- **AC-4**：用户点击“深度研究”后 SHALL 在同一路由进入 `research`，不得导航到旧个股分析详情路由。
- **AC-5**：`research` SHALL 复用现有预测、风险、技术信号矩阵、财务、研报、新闻和公告模块及其数据契约。
- **AC-6**：深度研究数据 MUST 仅在首次进入 `research` 时请求，并由独立加载、错误和重试边界承接；失败不得清空快速行情内容。
- **AC-7**：旧 `/home/market/analysis/$symbol` SHALL 兼容到 `/home/market/stock/$symbol?mode=research`；`/home/market/analysis/compare` MUST 保持独立且不重定向。
- **AC-8**：模式、股票和必要的来源上下文 MUST 写入 URL；刷新、前进和后退后 MUST 恢复同一股票与模式。
- **AC-9**：桌面和移动端 SHALL 只呈现一个股票身份头、一个主动作区和一个确定的返回路径，不因合页产生重复头部或重复收藏操作。
- **AC-10**：预研模式下，K 线、行情、资金、当前标的和关键结论 MUST 保持可见；深度区域部分失败 MUST 独立展示。
- **AC-11**：视觉设计 MUST 经用户确认后才能创建生产实现任务。

## Impact

- Web 路由：统一个股详情路由、旧详情重定向、导航和面包屑。
- Web 页面：快速详情与深度分析组合页面、共享股票头、模式切换和按需加载边界。
- 数据请求：初始仅请求快速模式数据；深度分析查询延迟到进入 `research`。
- API：新增轻量只读预测端点，不改变现有聚合响应；数据库、Quant 和预测计算无变化。
- 可视化：新增页面模式、切换交互、加载/错误/部分成功状态和响应式布局。
- 兼容性：旧个股分析详情 URL、内部链接、搜索入口、对比路由和返回链路需要保持可用。
- 回滚：恢复旧详情入口和旧个股分析详情路由，保留统一路由为未启用状态；不改动数据。

## Visual Design Impact

Visual design: required.

- 目标页面：单只股票统一工作台。
- 参考基线：最新生产对齐的快速行情详情与个股分析工作台。
- 受影响状态：快速模式、研究模式、模式切换加载、行情可用但研究失败、研究部分成功、无研究数据、无足够 K 线、陈旧行情、移动端、浅色/深色、键盘焦点和 reduced motion。
- 视觉探索必须验证股票身份头、模式切换、快速与深度内容的分层、K 线上下文保持、深度模块加载过渡和移动端的纵向阅读顺序。
- 探索稿必须保存在 `docs/design/prototypes/explorations/`，不得覆盖现有确认基准。
