# Proposal

## Why

当前行情详情页只提供 K 线，无法把实时估值、研报原文、机构预测、财务数据、资金筹码和新闻事件组织成可追溯的个股研究结论。用户需要围绕单只股票获得统一分析入口，并明确区分事实、模型情景和 AI 归纳。

## What Changes

- 在“市场情报”下新增“个股分析”，支持按名称或代码检索，并从现有行情详情页互相跳转。
- 新增个股分析页，展示行情、技术趋势、研报、一致预期、情景预测、风险参考区间、财务估值、资金筹码、新闻公告和数据完整度。
- 新增东方财富研报和 PDF 数据能力，使用 `a-stock-data` 规定的端点、字段和东财限流入口。
- 新增同花顺一致预期 EPS、mootdx/新浪财务、Baostock 估值历史、巨潮公告等数据能力。
- 下载并持久化研报 PDF；提取全文，扫描件使用 OCR 兜底。
- 将研报全文分块并使用本地 BGE-small 生成 512 维向量，写入 PostgreSQL + pgvector。
- 新增研报检索 Agent 工具；AI 结论必须引用结构化数据或研报页码。
- 数值预测和风险区间由确定性代码计算，LLM 不直接生成价格数值。
- 研报和财务数据按主动分析标的及自选股同步，不做全市场高频拉取。

## Capabilities

### New Capabilities

- `stock-analysis-workbench`: 个股分析页面、模块、数据时效、风险标签和行情详情联动。
- `stock-research-documents`: 研报元数据、PDF 存档、全文提取、OCR、分块、向量检索和证据引用。

### Modified Capabilities

无。

## Impact

- 前端：市场情报导航、个股搜索/列表、个股分析页、行情详情入口。
- 后端：个股分析聚合 API、研报与文档 API、受控 PDF 下载、Agent 研报检索工具。
- Quant：研报/预测/财务/估值 provider、PDF 提取与 OCR、技术指标与统计情景计算、本地 embedding。
- 数据库：研报、文档、分块、预测、一致预期、财务、估值和分析快照表。
- 存储：新增共享 `reports-data` 持久卷；全文和向量存 PostgreSQL。
- 依赖：PDF 提取、OCR、本地中文 embedding、pg_trgm。
- 外部数据：腾讯、mootdx、百度、东财、同花顺、新浪、Baostock、巨潮。
- 安全：研报和 PDF 仅登录用户可访问；来源许可和引用必须保留。
